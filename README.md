# Badgecord
Badgecord is a Discord Plugin that allows you to eguip all badges (only People with Badgecord installed can se the chages) 
## Imporant info
- We are planing to become a Vencord plugin but we arent at the moment
- We know that client changes are against the discord ToS
- We also have our own ToS (not ready at the moment)
- We have a own [Discord server](https://discord.gg/bcNguWQ7ne) and a [Telegram Channel](https://t.me/Badgecord_official)
- We do our best to make the badges look as authentic and high quality as possible

## Security and privacy 
Even if nothing has been released yet, we will use a server and a registration system, just like our own Terms of Service, to prevent botting, scams, etc. We do not use any information Besides the username for display and so that we have badge coordination, the profile picture is also required for display.
